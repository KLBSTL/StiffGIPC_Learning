# IPC legacy MAS 阶段归因与质量标准边界（2026-10-05）

**计划中的单系统阶段探针已完成：f2/direction1 固定输入下，首先出现可测重复差异的是限制（restriction）阶段，且本批差异全部位于粗层。** 固定限制输出后，局部作用三次观测逐位一致；固定局部输出后，延拓三次观测逐位一致。整个 MAS 作用仍有约 8e-8 的相对重复差。

这把“整个 MAS 不重复”的旧结论缩小为一个具体阶段。它不是对100帧材料差异全部成因的证明，也不是新的速度或质量通过结论。

## 1. 用户问题：质量不同是不是算法必然结果

**两种结果满足同一组预声明质量指标，却有明显轨迹差异，是可能的；质量退化不是执行加速的必然代价。** 拉伸、安全或残差标准约束的是某些性质，不唯一确定所有顶点的位置、速度和接触时刻。用途若主要是视觉仿真，可在充分的材料与安全证据下接受轨迹差异；若要预测轨迹、受力或接触时刻，还需要相应参考与准确度证据。

IPC 原论文明确分开动力学准确度与接触几何准确度；GIPC 的补充比较还检查非线性梯度收敛、轨迹与能量，不能把一个线性 PCG rho 阈值当作完整质量认证。[IPC 作者项目页](https://ipc-sim.github.io/)；[GIPC 作者补充材料，§9](https://kemenghuang.github.io/img/ipc_paper-suppl.pdf)。更完整的论文和本项目证据见[质量标准分析](ALGORITHM_QUALITY_CRITERIA_20261005.md)。

本项目应区分三类变化：

| 变化 | 可以预期什么 | 不能预先声称什么 |
|---|---|---|
| IPC host → Graph、执行组件 | 数学目标与停止规则相同；浮点求和顺序可产生微差，再经接触与停止分支放大 | 加速必然变差，或必须逐位相同才算正确 |
| legacy → gated/compensated 停止 | 有限精度、有限迭代的终端状态可能不同；需独立评估质量与新增工作 | 残差更小必然拉伸更小、必然更快 |
| IPC → AL-TOI 接触求解 | 接触子问题和状态时序不同，有限迭代结果可能不同 | 只要没有碰撞即可称同动力学准确度 |

当前计划已经采用“材料不退化，轨迹分岔单列”。因此厘米级轨迹分岔不是单独自动否决项；固定兔子候选最大边长比 1.038670877 超出冻结 1.036172766 则属于材料真实越界。原版本身也超界，使旧协议不能认证，但不把候选越界改写为“双方已达标”。旧门槛、失败记录和默认推广判定均保持不变。

## 2. 实施与有限预算

新增 `fixed_mas_stage_study=false`，只在 IPC legacy MAS、独立 fixed 诊断、最终选定帧的第一个方向允许开启。生产默认为关闭；配置和 resolved_config 同时记录是否生效，冻结旧程序拒绝此新开关。旧配置缺少该字段仍兼容，旧身份不重写。

选定系统：固定兔子布料，从零推进，dt=.01，f2 第一个方向，17340 个全局标量自由度；MAS 部分5776节点、6176映射节点、6656层级节点、5层。MAS 子系统偏移为4个三维块，即12个标量自由度，独立分析核对了输入 r 与全局 b 的该片段逐位一致。

四阶段各1次预热＋3次观测，总计16次**阶段重放**。底层实际调用旧限制/局部/收集 kernel 各8次，合计24次 kernel 作用。没有新数值 kernel，没有旧128次微基准、PCG严格阈值重放或参数扫描。每次场景运行上限120秒，实际探针运行约1.89秒；另一次两帧关闭对照约1.13秒。含同步和导出的诊断耗时不作为加速比。

保护方式：原 MAS R/Z 所有权移入作用域守卫，另配私有 scratch；限制使用同一克隆 r，局部每次使用同一份预热限制输出，延拓每次使用同一份预热局部输出。粗层保持原清零规则；细层与最终输出用非有限值初始化后检查覆盖。因子/映射不重建；正常返回恢复原缓冲内容及地址、生产方向、全局 z。异常终止运行，不把异常轨迹当作恢复通过。

## 3. 分阶段直接证据

每次观测与该阶段预热输出比较：`||输出−参考||₂ / ||参考||₂`。这些是算子数值差，不能直接换算成米、速度或拉伸误差。

| 阶段 | 相对重复差范围 | 最大绝对分量差 | 不同分量数 | 判定 |
|---|---:|---:|---:|---|
| 限制 | 6.269e-8–3.207e-7 | 3.492e-10 | 63–73 | 已验证同输入存在变化；细层0，粗层63–73 |
| 局部作用，固定上游 | 0 | 0 | 0 | 本次三次观测逐位一致 |
| 延拓，固定上游 | 0 | 0 | 0 | 本次三次观测逐位一致 |
| 整个 MAS 作用 | 6.554e-8–8.380e-8 | 1.863e-9 | 14849–16470 | 已验证整条作用仍有变化 |

源码中的限制采用 FP32 粗层原子累加，与“仅粗层变化”的实测吻合。固定准备数据排除了本次差异由重新装配或因子准备引起；固定上游的 local/prolong 排除了把传播误差误认作这些阶段自身重复差异。

三个观察样本不能证明 local/prolong 永远确定；限制源头定位也不能证明所有非线性长窗分岔都由它引起。材料梯度装配和 SpMV 中的浮点累加仍是其他已知数值来源，本轮没有新增第二个追踪分支。

## 5. 决策与下一步边界

- **已验证：** 本固定系统上的第一处已测阶段差异位于 legacy MAS FP32 粗层限制；完整作用差异与旧探针量级一致。
- **支持但未证明：** 该微差经方向、线搜索、停止及接触分支放大，可能参与后续厘米级轨迹分岔。
- **待验证：** 消除此源后，固定兔子的长窗材料分布是否改善；是否还有装配/SpMV等其他来源主导。
- **未通过：** 现有质量认证、执行组合默认推广和阶段性能目标。本轮没有新长测、AutoDL或默认数值路径变更。

后续若继续数值候选，只允许一个默认关闭、限定粗层限制的候选，复用同一冻结因子与映射，先验证输出精度、转置/正性、真实线性残差和默认 PCG 工作量，再按准备成本加实际应用成本判断。没有成本/质量优势就封存，不把整套慢稳定 MAS 替换进 IPC，不全局收紧 PCG，不把确定性单独扩展成长任务。质量与轨迹仍分别报告；当前证据不支持新建或放宽质量门槛。
