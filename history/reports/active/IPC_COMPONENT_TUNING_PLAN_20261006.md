# 已实现组件的有界优化与改错

本轮围绕现有 MAS final-dot、SRBK SpMV/pAp、普通 BVH refit、双容差补偿入口工作。优先修复普通与 swept 共享存储造成生产 refit=0 的限制；线性融合只做一次有证据的小修订。复用 benchmark-regression 的构建、实际生效、指标相互核对流程。不得以放松收敛、减少请求帧数或删除完整 CCD 获取加速。

## 实施边界

普通 BVH 在原独立开关开启时维护 ordinary/swept 两套拥有缓冲。切换采用所有权交换，不复制全部树。两套各自失效与周期重建；ordinary 每次更新全部当前 bounds，FullCCD 保留全部 swept bounds 和查询。默认关闭路径不分配备用存储。额外显存与切换/重建/生产 refit 单列。

MAS/SpMV 的 CPU 配置准备及 GPU kernel 数量先静态审查，最多一个小修订；只允许修改执行与缓存，不改变 A/b/M 的数学定义、PCG rho 和实际预算。双容差补偿保持现有 .001/.03/min6，单独兼容诊断，不混入最快执行配置或宣称停止规则减少工作。
