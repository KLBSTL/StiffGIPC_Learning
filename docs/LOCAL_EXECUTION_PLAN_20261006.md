## 固定执行顺序

1. 本机全新构建；组件/PCG 边界/接触池/停止模块测试，六历史 M 作用回放，
   当前完整固定系统 host/Graph 对照。六 M 回放不称为六个完整 A/b/M PCG。
2. 固定兔子 59 帧质量因果对照：off1/base1，base2/off2，on1/off3/base3。
   每小轮写分析并由主任务复核后才进入下一轮。首先回答质量差异来自当前
   通用路径、接触池，还是基线重复范围；不因新 GPU 结果自动放宽旧协议。
3. 悬挂 51 帧 off/on 三轮交错，结合固定场景对接触池做真实成本评估。
   Typed-pair/energy 守卫与性能运行分开，验证成本不能混成组件开销。
4. 依这轮工作量和阶段成本，选择一个有界执行修订，或一个已有组件消融。
   只改一个假设；完成后重复正确性、质量、速度分析，再决定下一轮。
   最多再开展两个有证据的实验方向，避免继续无限调参。
5. 只有硬失败为零且质量获得支持，才进入 100 帧与长稳定性检验。
   材料、完整 CCD、legacy .01/min6、PCG rho 1e-4 不变。

## 资源与结论边界

GPU 实验串行，每次短窗/100 帧上限 120 秒，300 帧上限 600 秒。
不延长失败预算、不结束无关 GPU 应用、不降低原显存保护。当前本机 GPU
负载和显存不足会阻止完整窗口，期间继续 CPU/构建/离线分析；部分轨迹和
负载不可控结果不能认证加速比。停止规则实验与执行优化分别报告。

2× 是用户目标。没有测到同质量 2× 前明确报告未达成；每轮负收益分支
停止推进，代码与实际能力标识保持一致。正式默认推广继续受质量验收约束。
