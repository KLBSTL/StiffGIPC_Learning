# PCG Graph 后续有限优化计划

2026-10-06。先冻结计划，再实施；本轮只使用本机。起点为 `c1e98f892ced288e6b76830fc5989f9421ddaa71`，历史报告和失败数据保留。

## 目标与依据

同质量相对原版 Stiff 达到 2×仍为挑战目标，本轮不承诺达到。当前两个布料窗口的完整线性阶段占 wall time 约45–46%。整窗净省5%至少要求线性总阶段净省约11%，净省10%要求约22%。旧 Nsight 中 WHILE 回边空隙中位30.272µs包含诊断影响，不能当作生产收益。

本轮只检验一个主要假设 H1：固定 K=4 子步的 conditional Graph body，通过减少 WHILE 回边降低总求解成本。它增加守卫、节点和最多三个尾部 scratch 子步，不是减少总 kernel 数。不得改变 PCG rho1e-4、IPC legacy/.01/min6、dt=.01、材料、MAS精度及完整CCD。默认仍为 K=1。

## 顺序、预算和决策

1. **语义与实现**：保持 K=1 路径；K=4 使用独立 active 状态和 dot scratch。停止后 x/r/p、逻辑标量、首次错误冻结；先完成多 block p 更新，再由独立单线程 finalize 更新 active。未保护的 fused diagonal update 与 K=4 拒绝组合。配置、缓存 key、统计明确记录 K。
2. **边界验证**：运行现有六项 CTest，并新增真实生产 kernel/conditional Graph fixture，覆盖块内第1–4步停止、零 RHS、预算边界、非正/非有限曲率、首次错误保留、多 block 向量及 poison scratch 尾部。测试逻辑使用生产守卫，不以复制公式代替。CPU配置合同检查严格拒绝不支持的组合。
3. **固定系统非追踪重放**：先固定兔子 f2/n1，再 f57/n1，必要时悬挂 f41/n1；最多三个从零推进批次，单次120秒。从同进程完整 A/b/M 和 x0=0开始；每臂2次预热、7组交错配对。独立私有缓存；分别记录首次捕获、warm完整求解wall/GPU时间、初始化/读回、迭代量、真残差、解差和算子身份。恢复生产解、统计、Graph缓存及缓冲状态；不跑旧容差网格。不得混入追踪时间或把捕获成本隐藏在速度结论之外。
4. **逐步分析**：每个批次后检查正确性、工作量及收益再开始下一批。K4完整线性重放没有稳定15%收益，或实际整窗潜力不足5%，封存本分支。最多一次有明确证据的修订；不做 K=2/4/8 网格，不追加 Nsight。
5. **布料窗口**：只有固定系统通过才启动固定兔子59帧/悬挂51帧，各3组交错 K1/K4，共最多12次；核对分项成本、方向/PCG/线搜索量、材料指标、位置及实际速度。整窗净省至少5%且无明显质量回退才保留；阶段目标仍为两布料几何平均相对当前 Graph 至少1.10×，任一场景不回退超过3%。未达门槛不进入100/300帧或新默认。

GPU实验串行；保持既有显存、磁盘、外部进程保护及120秒绝对上限。共享 WDDM 负载只能报告诊断速度。短窗不能认证同质量2×，默认 rho 停止量不等于真实线性残差。
