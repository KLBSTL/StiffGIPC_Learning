## 两个候选与进入门槛

对应可优化热点必须占整场至少10%，理想减半整场潜力至少5%才实现。诊断事件、profiler开销和嵌套CPU等待不能当作可省成本。不能由整个linear或line-search比例推断单个算子占比。

- A：batch能量九段CUB分段求和。保持生产kernel、空段零、ABD路径和最终求和顺序；独立workspace。未来接口`energy_reduce=per_term|segmented`，默认旧路径。
- B：对称SpMV行邻接视图。非对角双引用、对角单引用、保留原数值；每系统准备、PCG内复用；256线程/块、一warp/块行；直接写`aAx+by`。未来接口`spmv_backend=legacy|row_gather`，默认旧路径；地址/容量/尺寸/后端进入Graph失效判断。
- 未达到热点门槛时不新增相应入口，记录“跳过”，不保留空实现或静默回退。
- 各最多一次修订。完整能量/线性路径需提升至少15%；再做三对100帧，整场增量至少5%，另一场景回退不超过3%。

## 验证与停止

算子CPU FP64参考误差不超过1e-10；准确线性参考真残差不超过1e-8，默认PCG输出不冒充准确解。复用零RHS、收敛、breakdown、触顶、地址变化和Graph重放守卫。

材料检查整段最大/p99拉伸、FEM最小J/负体积、ABD翻转/漂移；位置和真实速度分体报告。基线复核失败时可以保留诊断探索，不能认证质量、推广默认或启动条件300帧。

仅通过局部、整场和质量门槛的最终组合进入七对四臂确认、独立100帧接受路径CCD审计，及条件300帧/600秒和混合100帧回归。两布料相对当前Graph几何平均至少1.10×、任一不回退超过3%；相对原版2×仍需完整质量及受控负载。

本轮不重开K4、池、旧融合失败分支，不改变停止规则或预条件器，不扩展混合精度、多流全求解器、OptiX、多卡等路线。没有满足门槛的候选则提交成本证据与未达标结论。
