# 算法差异、质量达标与轨迹分岔的边界（2026-10-05）

**可以出现“两种方法满足同一组预声明质量指标，但轨迹差很多”。这不意味着质量差异是算法的必然代价，也不意味着两种轨迹都已被证明是同样准确的物理解。** 本项目当前要求材料指标不退化，位置和实际速度另报；并没有要求逐点轨迹或浮点比特完全一致。当前固定兔子候选确有材料越界，而原版本身也会越界、重复分岔，两件事都不能被省略。

本文件只读已有源码/结果并核查原论文和 NVIDIA 官方资料；未运行 GPU，未修改求解器、界限或已有结论。

## 1. “算法相同”需要分层说清

| 改动 | 原本希望保持的内容 | 为什么仍可能分岔 |
|---|---|---|
| IPC host → conditional CUDA Graph | 同一物理目标、停止规则、矩阵与 PCG 更新；改变提交与控制位置 | 浮点累加顺序、并行调度、标量判定边界可能不同；也必须排除图地址/缓存/缓冲使用错误 |
| FullCCD refit、批量能量、合法能量复用 | 候选集合、安全 CCD、当前目标能量的计算含义 | 遍历/归约次序变化可改变舍入；错误筛选或缓存失效也能造成真实错误，需要分别验证 |
| legacy → gated/compensated 停止 | 材料模型保留，但求解到哪个状态不同 | 新出口延迟、额外 Newton/PCG 和接受步改变；它不是单纯执行优化 |
| IPC → AL/Robust TOI 接触后端 | 用户期望的物理模型相同，数值求解流程不同 | 接触线性化、乘子/罚项、状态更新和停止时序不同；近似误差及求解路径不能默认等价 |

前两行是**设计上的数学同义目标**，不能仅凭命名宣布实现已经等价。若固定输入下算子不一致、读取失效缓存或丢安全接触对，属于实现问题；不能用“GPU 本来不确定”解释。只有排除这些问题后，才可以讨论舍入和数值敏感性。

浮点加法不满足结合律，FMA 与分开乘加、串行与树状点积可得到不同舍入结果，这是 NVIDIA 官方给出的明确事实。它说明逐位相同不是数学同义执行优化的必要要求；**它没有保证差异永远微小，更没有证明本项目全部大分岔都由舍入造成。** 后者仍是需要探针验证的因果假设。[NVIDIA《Floating Point and IEEE 754》，§2.2–3.2、§5.3–5.4](https://docs.nvidia.com/cuda/floating-point/index.html)

在相同输入、目标及唯一局部解的理想条件下，充分收敛的等价求解器应趋向同一解。但当前有限容差、分支式停止、接触更新与跨帧状态继承不满足“精确求解后逐帧等价”的已证明前提。微小方向差可能改变某次回溯/退出，随后新的接触与速度状态再放大差异。这是合理机制推断，尚不是“已证明该布料系统混沌”或“必然退化”。

## 2. 论文不是只设一个数就证明所有质量

原 IPC 研究把动力学精度与接触几何精度明确分开，并区分可行性、用户指定准确度以及面向动画的较低准确度用途。零碰撞本身不等于力学解准确，动力学停止量也不能代替几何安全。[IPC 2020 作者项目页及论文摘要](https://ipc-sim.github.io/)

GIPC 的原补充材料 §8–9 不只给 PCG `1e-4`：它用非线性梯度范数比较直接解法与 PCG，解释方向停止量会随线性求解器改变，并考察不同收敛要求。这里的 PCG 停止量是预条件残差相关量；不能改称真实线性相对残差 `1e-4`，也不能改称材料/位置误差上界。[GIPC 原补充材料，Tables 1–4、§9](https://kemenghuang.github.io/img/ipc_paper-suppl.pdf)

StiffGIPC 采用的是**非严格的立方 strain-limiting 能量**，不是硬应变上限。原论文 §5.1、§7.1 明确承认极端情况下不保证严格应变约束：Fig.13 的挂布对照中，barrier 方法最大主拉伸约 1.098，而默认立方模型约 1.35，作者同时报告平均值并说明适用性。这体现“实用效果相似”与“最大应变严格相同”是不同主张；它不能成为本项目事后放宽峰值标准的依据。论文的主拉伸、材料设置与本项目网格边长比也不是同一指标。[StiffGIPC 作者原文，§5.1、§7.1、Fig.13](https://kemenghuang.github.io/img/stiff_gipc.pdf)

因此可以学习论文**按任务明确质量目标并分别给证据**，不能将论文某个容差拿来当所有项目的一项通用认证。

## 3. 达标与同轨迹是不同命题

设质量要求为 `Q(x,v) ≤ q`。两轨迹都满足它，只说明两者属于允许集合；这个集合通常包含许多不同形状、速度和接触历史。即使只有两个点组成的定长线段，其长度合格也没有确定线段方向和角速度。由此推到布料：峰值/p99 拉伸与无碰撞都合格，也不能推出每个褶皱、接触时刻或节点速度相同。

| 声称 | 所需证据 | 当前不能替代它的量 |
|---|---|---|
| 安全 | 独立接受路径 CCD、有限状态、固定物体正常等 | 端点 RMS、求解残差 |
| 满足预声明材料指标 | 全程峰值/高分位拉伸、混合 FEM/ABD 指标等 | 单张截图、平均值、零 CCD 标记 |
| 求解当前离散问题足够准确 | 完整目标/梯度、真实线性残差及有效停止语义 | PCG rho 单独达标、累计 beta 单独达标 |
| 与基线轨迹接近 | 分体位置/实际速度及基线重复差异 | 上述材料指标单独达标 |
| 物理预测正确 | 对可靠参考、解析/收敛或实测的适用性验证 | “与一条基线轨迹接近” |

材料合格、轨迹不同在应用层可以接受，条件是用途与指标预先声明、指标足以覆盖该用途，并诚实限定结论。若用途是精确接触时刻、受力或轨迹预测，只有拉伸/碰撞标准就不足。残差很小也不自动给位置误差界；从残差到解误差还需要条件数、局部稳定性/唯一性等额外前提。

## 4. 本项目当前事实不应被改写

源码核查：原版和活动 `solve_subIP` 都有 movement 出口及第六轮后的累计 beta 出口；active gated/compensated 显式替换累计出口，仍保留 movement。`core/GIPC.cu` 在装配后检查上一轮 `_moveDir`；所以不能把 movement 退出说成“当前完整梯度已满足新门控”。执行组合仅在目标未改变等条件下复用能量。

已有正式矩阵中，固定兔子组合 Graph 一次峰值达 `1.038670877`，高于预先冻结 `1.036172766`。这是材料指标的真实超出，不只是“轨迹看起来不同”。同轮 raw 原版 0/3 通过（两次 p99、一次峰值越界），说明这个旧 observed 标定范围又不能可靠迁移到正式 raw 条件。**当前合理结论是旧协议不能完成同材料质量认证，不能直接判候选必然退化，也不能直接判候选通过。** [本机实施结果](IPC_EXECUTION_RESULTS_20261005.md)

新五轮纯基线三臂诊断 raw_off/observed_off/observed_on 分别 3/5、4/5、4/5 通过旧界限；配对变化方向不稳定，同臂/跨臂轨迹范围重叠，首次可见分岔集中 f25。它支持基线重复敏感性需要定位，没有证明速度观测严格中性。旧失败标签继续保留，不能拿新最大值或挑选通过样本追认旧候选。[五轮独立复核](QUALITY_PROTOCOL_REVIEW_20261005.md)

悬挂场景的执行组合材料 3/3 通过、轨迹差落在已观测重复范围附近，可以单独报告这部分积极证据；它不能替固定兔子认证。独立 CCD 的 2435 条路径零标记只覆盖四条审计轨迹，也不能覆盖全部计时组或材料超界。

## 5. 下一步如何有界判别

保持现有物理参数、停止规则和门槛，配合主代理正在实施的**默认关闭、单 f2 legacy MAS 阶段探针**：

1. 对同一进程中受保护的完整输入前缀，核对算子每阶段实际输入身份及输出，找到首次超出重复噪声的阶段；独立重复运行只能给线索，不能将不同输入下的输出差认成算子错误。
2. 对探针取得的固定 A/b/M，先查有限值、对称作用、正二次型/实际 rho 和准确参考；再区分矩阵/预条件准备差、作用累加差、PCG 归约/停止差。只在可靠冻结系统上作局部对照，不全局收紧 PCG、不临时延长预算。
3. 若固定输入作用差属于舍入且算子检查通过，记录大小及其后续首次回溯/停止分支变化；若发生负曲率、非有限、明显非对称或错误缓存，先按实现错误处理。两类结论均不能单凭 f2 探针宣布完整 100 帧质量通过。

本轮不新增长测或参数网格，不改变旧协议。若未来决定采用应用质量标准而不要求轨迹接近，应另行预声明用途与未来验收，不能以此追认已有失败数据。可以说“满足这组材料与安全指标且更快，轨迹存在差异”；只有取得相应参考/误差证据，才能进一步说“同等动力学准确度”。

## 6. 状态

- **已验证：** 浮点实现可在数学同义时改变数值结果；原始论文区分安全、求解与材料质量；本项目既有真实材料越界，也有原版本身重复分岔。
- **支持但未证明：** 小方向/舍入变化经停止与接触分支放大，是当前分岔的一种合理解释。
- **待验证：** 首个产生不可接受差异的具体阶段、候选是否存在独立系统性材料退化、未来适用质量协议。
- **不成立的推论：** 加速必然要牺牲质量；所有轨迹差都说明实现错误；零碰撞或同一 PCG 阈值足以证明同质量；新范围可追认旧候选。
