# 稳定 MAS 限制算子候选：预声明门禁

本协议在候选 GPU 实验之前保存。只改变 FP64 求和顺序；默认仍为 serial，不改变 A、接触模型、Cholesky 因子、延拓、rho、Newton 或 TOI 停止条件。

## 进入原因

- `TOI_COST_SERIAL.json`：三个窗口的固定输入探针中，限制 652.021 ms，局部作用 224.439 ms，MAS 总应用 885.863 ms。限制占比 73.6%。探针不计为生产工作。
- `active_serial_nsight_node_validated/nsight_cuda_gpu_kern_sum.csv`：第25帧首个线性系统，限制 kernel 34.868 ms、占 GPU kernel 时间60.1%；三角作用13.339 ms、占23.0%。这是一份真实生成的节点追踪，Graph 粒度报告另外保存。
- 首次异常系统 CSR 最长行19193项；绝大多数行很短。原实现一个线程串行累加整行。采用一个warp固定分段累加，再按16、8、4、2、1固定树合并，数学 R 不变。

## 有限实验与判断

1. 同轮 serial/warp 六份历史失败系统：10个输入、Graph重放、缓冲增长、独立CPU作用、正二次型和对称性。任何异常即失败，不在一次PCG内切换。
2. 三个从零推进新窗口完整A/b/M系统；CPU准确解真残差不超过1e-8。默认rho=1e-4候选比较实际真残差、误差和PCG迭代量，不把两种残差阈值混淆。
3. 固定A/b/M的受保护对照必须保留主解和算子数据；默认停止参数下分别测host和Graph。运行前预热，串行/并行交错；中途异常退出并保留失败。
4. 两组35帧按serial/warp/warp/serial顺序，单次120秒；一个35帧成本探针180秒；一个25帧Nsight节点追踪120秒。均为共享桌面诊断。
5. 准备成本加实际PCG应用成本后，线性阶段没有稳定改善至少15%则不推广。即使局部通过，只要轨迹质量或迁移门禁未通过，也不启动100/300帧最终认证，不宣称相对Stiff达到2×。

v55/v56三角作用路线本轮不重试：更大的限制热点尚未处理。没有新参数网格。
