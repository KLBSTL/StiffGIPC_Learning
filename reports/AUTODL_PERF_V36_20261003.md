# AutoDL v36：固定系统精度、执行成本与安全更新诊断

本轮在独立目录 `/root/autodl-tmp/stiff_toi_cudagraph_20260929/v36_20261003` 执行。RTX 4090、CUDA 12.8、Release sm89；性能运行串行，运行前记录 GPU 空闲样本。旧 v34/v35 源码、二进制和结果保留。v36 默认数值算法与阈值不变；新增诊断不作为正式速度测试。最终同精度比较的补充结果见本报告末尾。

## 1. 实现与身份

- 独立源码：`sources/stiff_perf_v36`，由冻结的 `stiff_perf_v34_cuda128` 派生。
- 新增选定物理帧/线性系统的固定输入研究：同 A/b、相同预条件器、零初始解，对比 host、Graph、Graph 融合。固定迭代模式仅在研究内生效；结束恢复原始解和配置。
- 导出对称 3×3 块 COO 的矩阵、右端项、各精度/后端的解、全局 diag 与 ABD 逆块；验证研究前后的系统指纹及主解恢复。MAS 内部层次数据未完整导出，只记录在进程内复用与签名，不能称为完整离线 MAS 重放。
- 新增失败系统导出：异常或 PCG 达上限时保存当前 A/b 和可支持的预条件器数据。
- 安全更新计时细分为状态混合/体积检查、BVH、候选生成、原生端点交叉检查和状态发布；完整 CCD、候选生成与原生检查全部保留。
- 固定清单覆盖 557 文件。CUDA 构建成功，融合夹具 28 组、108108 值逐位一致；`ctest --test-dir builds/autodl-stiff_perf_v36 --output-on-failure` 为 1/1 通过。此 CMake 配置只注册了融合夹具，不代表全部物理功能都有 CTest 覆盖。

## 2. 固定系统：分离工作量、精度和执行成本

布料–球 diag 采样 8 个系统，悬挂布料 MAS 采样 5 个系统。请求帧为 1/22/40/70/100，选取存在的第 1/8 个线性系统。每种设置预热一次，再测三次；固定迭代数为该系统主求解迭代数与 64 的较小值。共记录 408 次求解比较。固定迭代模式只证明等工作量成本，不要求此时已收敛。

| 场景/预条件器 | 固定迭代 Graph/host 中位耗时比 | Graph 融合新增中位比 | 同输入算子重复差 |
|---|---:|---:|---|
| 布料–球 / diag | 2.091× | 1.022× | SpMV 最大约 3.6e-16；预条件器逐位相同 |
| 悬挂布料 / MAS | 1.991× | 不适用 | SpMV 最大约 2.0e-16；MAS 最大约 1.13e-7 |

上述比值是各固定系统三次计时中位数之比，再跨系统取中位数；不是整段仿真加速比。Graph 预热排除了首次图捕获。算子计时为 128 次批量调用的主机墙钟均值，含正常提交与最终同步，不能当作纯 GPU kernel 时间。

| rho 比阈值 | 布料–球最大真相对残差 | 最大同后端重复解差 | 悬挂布料最大真相对残差 | 最大同后端重复解差 |
|---|---:|---:|---:|---:|
| 1e-4 | 7.310e-2 | 1.119e-3 | 2.403e-1 | 2.933e-4 |
| 1e-8 | 7.566e-4 | 3.024e-5 | 2.689e-3 | 3.766e-5 |
| 1e-12 | 7.197e-6 | 3.567e-7 | 2.661e-5 | 3.073e-7 |

同矩阵使用 SciPy 独立重建后核对导出解的欧氏真残差；布料–球 CPU/GPU 残差最大绝对差约 6.9e-15。所有研究均通过系统指纹不变、RHS 不变与主解逐位恢复检查；MAS 该检查只覆盖已导出缓冲和指针签名。

结论：Graph 确有独立于迭代工作量的执行收益；融合的约 2% PCG 局部收益不足以推导稳定整场景收益，继续默认关闭。diag 路径的重复差随精度提高显著减小；MAS 本身仍存在约单精度量级的重复差。源码的 MAS 多层向量/局部运算使用 float，并含原子累加；这是与观测相符的解释，尚未完成首次差异内核的因果隔离。

证据：`AUTODL_PERF_V36_SPHERE_FIXED.json`、`AUTODL_PERF_V36_HANG_FIXED.json`；导出快照在下载包各研究运行的 `fixed/`。

## 3. 完整 100 帧精度核查

| rho 比阈值 | 最大 Graph/host 相对解差 | 最大 host 重复解差 | 最大真相对残差 |
|---|---:|---:|---:|
| 1e-12 | 8.740e-6 | 8.887e-6 | 1.161e-5 |
| 1e-14 | 6.759e-7 | 1.178e-6 | 1.155e-6 |
| 1e-16 | 9.023e-8 | 6.743e-8 | 1.218e-7 |

三条均完成 100 帧、无求解上限。1e-16 的布料–球 diag 运行通过 Graph/host `1e-6` 同系统解差门槛。该结论只覆盖这一运行的逐次系统；不是所有场景认证，也没有证明 host 重复达到早期更严的 `1e-12` 门槛。审计重复求解和同步的耗时不可用于正式速度比。

另有各三次交错的 TOI+Graph 轨迹精度比较（suite=1、diag、dt=.01、Newton=.01、velocity_tol=.05）：

| rho 比阈值 | 中位求解秒 | 同配置最大布料 RMS 重复差 |
|---|---:|---:|
| 1e-8 | 4.8934 | 1.3221% |
| 1e-12 | 6.6885 | 0.00008553% |

线性精度能显著改善该场景的轨迹重复性，但成本上升。不能把默认配置的低耗时继续用于严格精度结论。所有默认停止参数未改。

## 4. 安全更新热点

每配置额外单次 100 帧同步诊断，以下为每个已接受 outer 的平均毫秒；不同配置的工作量不同，不能直接据分项总时间作优化收益判断。

| 场景 / suite | BVH | 候选生成 | 原生交叉检查 | 混合及发布 |
|---|---:|---:|---:|---:|
| 布料–球 / off | 0.2455 | 1.5082 | 0.7705 | 0.0306 |
| 布料–球 / on | 0.0563 | 1.5851 | 0.7343 | 0.0312 |
| 悬挂布料 / off | 0.2501 | 0.9296 | 0.3383 | 0.0250 |
| 悬挂布料 / on | 0.0541 | 1.1272 | 0.3622 | 0.0253 |

suite 开启后，安全更新中主要成本是候选生成与端点检查，而非 BVH refit。`buildCP()` 内含候选计算和两次计数读回；本轮阶段计时还未拆开 kernel 执行、CPU 提交与读回等待。远端未找到 `nsys`，没有伪称已完成 CUDA API 级归因。下一步应在固定几何输入上测这几项，验证计数读回合并等小改动；不得通过跳过原生交叉检查获取收益。

## 6. 共同参考仍需验收

先以官方 base，Newton=.001、PCG rho=1e-8，在同一物理时长 1 秒下细化时间步，并以公共 .01 秒采样时刻比较布料质量加权 RMS / 初始布料包围盒对角线：

| 比较 | 最大轨迹差 |
|---|---:|
| dt → dt/2 | 1.546% |
| dt/2 → dt/4 | 2.363% |
| dt/4 → dt/8 | 4.169% |
| dt/4 自身重复 | 1.004% |

差异没有随细化降低，该组参考不支持充分收敛真值声明。TOI rho=1e-12 对 dt/8 的约 5.90% 差异不能称为真实物理误差。再收紧 TOI 非线性参数（Newton=.001、velocity_tol=.005）也未建立与参考的一致性，单条轨迹差约 6.03%。因此继续追加更严格官方 base 参考探针，结果见末尾补充。

## 7. 兔子失败系统

当前 v36 MAS+Graph 完成 34 帧，在第 35 帧线性求解达到 18257 次上限，拒绝不收敛 trial。末次真相对残差 6.888，rho_stop 322608.56；本次并未出现旧诊断中的负 rho，不能混用历史失败的数值。

成功保存实际失败 A/b：60858 DOF、165854 个 3×3 对称块。CPU 重建后 2802798 标量非零项，全部有限，相对不对称度 7.89e-17，无负/零对角项；最小/最大对角项约 2.835e-4 / 4.778e10。对角尺度跨度约 1.69e14，不等于已测出的矩阵条件数。

对称对角缩放后的最小特征值探针在 300 次迭代内未收敛；不能据此宣称正定或不定。对同一 A/b 的有界 CPU 标量 Jacobi-CG 在 3000 次后真残差降至 0.00701，仍未达到 1e-6；它与原生 3×3+ABD 或 MAS 均不同，也不能推出改成 diag 就能完成兔子轨迹。

下一步已可直接从该失败系统开始，检查 MAS 的 r^T M r、局部谱与接触项尺度，避免每次重新寻找失败帧。完整混合体 100 帧、材料条件和质量匹配仍未通过。

## 9. 同精度整段比较及最终决定

rho=1e-16、diag、suite=1、dt=.01、Newton=.01、velocity_tol=.05，TOI host/Graph 各三次 100 帧交错，均关闭审计，全部完成。

| 配置 | 中位求解秒 | 三次最大布料自身重复差 |
|---|---:|---:|
| TOI host | 14.6964 | 0.0716261% |
| TOI Graph | 7.9932 | 0.000000540% |

中位耗时比 1.839×。原计划全场景质量加权 RMS / 场景尺度 `1e-6` 轨迹门槛及更严格的布料单独门槛均为 2/3 配对通过；不得剔除第二轮后认证稳定同解收益。第一、三轮原门槛归一化差分别 1.08e-10、5.00e-9；第二轮为 2.65e-5，未过门槛。Graph 自身重复很小，但 host 的一个重复运行明显分叉，不能将其归因于 Graph。

host r1/r2 的布料 RMS 首次超过 1e-10 在第 25 帧，首次超过 1e-6 在第 62 帧。更早的第 22 帧第 2 个 outer，alpha 已有约 1.42e-10 的差异；该值本身不是根因证据。第 68 帧第 7 个方向首次观察到退出标签不同（full_step/velocity_converged），但二者均走退出分支且晚于位置门槛超限，不能将该标签差当作根因。下一次应从第 21–25 帧保存并重放状态、组装与活动集，找首次实际输入/算子差异，而不是继续放宽轨迹门槛。

同精度额外 Graph 路径独立 CCD 351 段通过，其中接受推进 252 段、静止桥接 99 段。三条本轮额外路径合计检查 1019 段：722 段推进、297 段桥接；零保守标记，逐帧起点/终点及子步覆盖已核对。仍不覆盖全部正式计时运行。

官方 base 再收紧至 rho=1e-16、Newton=.001，dt/dt2/dt4/dt8 及 dt4 重复均完成。相邻细化的最大布料差依次为 1.533%、2.344%、3.818%；dt4 自身重复仍约 0.489%。线性阈值收紧尚未解决参考不收敛问题，严格 TOI Graph 相对严格 base dt8 的 6.37% 只能记为轨迹差。

本轮共 50 次 GPU 运行：49 次按请求帧数完成，1 次兔子失败保留。没有通过数据选择、停止阈值放宽或删除安全检查获取加速。未选择新的默认性能改动：Graph 局部成本收益已被确认，但融合幅度小、完整轨迹门槛有失败；安全热点定位后仍需固定几何输入的候选/读回计时。v36 的交付是可审查的诊断实现、精度与成本证据、完整复测和失败系统。

### 后续优先级

1. 重放 host 自身第 21–25 帧的状态与组装，区分状态/候选身份变化与浮点误差放大；保留 rho=1e-16 作为诊断锚点，不直接改默认。
2. 对原生候选生成做固定输入分解，分开 kernel、计数读回和同步，验证批量读回候选；端点检查继续保留。
3. 对已保存兔子失败 A/b 做原生 MAS 作用量、对称性与正定性探针，补齐 MAS 内部快照；现有 CPU 谱探针不构成正定性结论。
4. 在自身重复误差受控后继续建立物理参考，才能认证 TOI 相对官方 base 的质量匹配收益。

最终 AutoDL 无活动 CUDA 仿真进程，GPU 0%、空闲显存 24081 MiB，数据盘余量约 4.3 GiB。最终结构化证据见 `AUTODL_PERF_V36_VERIFIED.json`、`AUTODL_PERF_V36_STRICT_VERIFIED.json` 和 `AUTODL_PERF_V36_FINAL_VERIFICATION.json`。
