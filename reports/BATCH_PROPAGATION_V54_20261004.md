## 固定兔子：持续规则差异与单帧状态差异分开测

两种配置每帧都持续使用各自退出规则时：

| 指标 | native | velocity_only |
|---|---:|---:|
| 第24–30帧Newton总次数 | 63 / 63 | 89 / 89 |
| PCG总迭代 | 8451 / 8455 | 11701 / 11830 |
| 窗口最大边长比 | 1.032997 / 1.032997 | 1.032876 / 1.032876 |
| 自身重复最大顶点差 | .167mm | 1.071mm |

同轮native/velocity_only第24帧最大位置差2.0875mm，到第30帧为36.843–37.050mm；质量加权布料RMS约4.35–4.41mm，即初始布料尺度的.192–.195%。PCG总迭代平均增加约39.2%，峰值拉伸仅略降，重复差异反而增大。含追踪、审计及固定系统重放，不能将本轮运行秒数当作正式性能收益。

这组不能单独证明首帧差异传播，因为后续每帧也在改退出规则。补充隔离对照把后续统一为native：

| 指标 | 首帧native状态出发 | 首帧velocity状态出发 |
|---|---:|---:|
| 后续25–30帧Newton | 50 / 50 | 46 / 46 |
| 后续PCG总迭代 | 7188 / 7189 | 6613 / 6615 |
| 自身重复最大顶点差 | .0091mm | .0630mm |

两种初态之间的最大位置差由第24帧2.0875mm增至第29帧约12.10mm峰值，第30帧约11.881–11.885mm；末帧布料RMS约2.391mm（尺度的.10568%）。明显大于自身重复差异，说明**首帧退出导致的完整状态差异，在共同后续规则下也会持续并扩大**。完整状态含位置/速度/接触历史，不是仅给单个顶点添加位移的实验。

仍不能据此判断哪条轨迹是物理真值，也不能把局部12mm差异直接等同于原混合体停滞的原因。末帧布料/弯曲能量并非单调地因更多迭代而同时降低，最大拉伸接近不代表轨迹等价。

## 落球第30帧：续算门槛失败，首个A/b却一致

原先第25帧是未依赖满步退出的阴性对照。本轮第30帧确有full_step：seed的outer1原始方向约.3313m/s、outer2约.1315m/s，均高于.05的小方向阈值。

恢复回读及起始顶点字节通过，首个A相对差最大1.68e-18、b约2.13e-16，满足既定1e-10门槛。但seed与续算终点坐标最大绝对差约.4467mm，速度约.04467m/s；两次续算互相也有.0274mm坐标差和.00274m/s速度差，超过预设1e-8。`V54_BATCH_SPHERE_GATE.json`明确保留failed，未把首A/b通过替代整帧等价。

分歧已经出现在第一Newton方向：三次主求解PCG均154迭代，但原始方向速度分别4.178740、4.178918、4.178922m/s。此时尚未发生本帧新一轮接触更新。随后PCG迭代数、接触增量及退出分支继续分岔。不能把这份落球状态当作可靠的同轨迹续算入口。

## 已保存系统上的CPU准确参考

对三份7815自由度的首个A/b分别用SciPy稀疏LU求解，并独立检查欧氏真相对残差。三者为7.24–7.45e-13，均通过预设1e-10门槛；CPU解彼此相对差3.69–3.92e-14。这是**当前固定线性系统的准确参考**，不代表完整非线性或物理参考已通过。

已有compact fixed-study包含同一A/b和预条件器上的零初值重复求解，system_unchanged/primary_restored_bitwise均通过：

| 指标 | 观察 |
|---|---|
| 同系统默认Graph重复解相对差 | 1.04e-4–2.47e-4 |
| 默认host重复解相对差 | 9.54e-5–1.92e-4 |
| 默认fused Graph重复解相对差 | 1.58e-4–2.75e-4 |
| 默认Graph欧氏真相对残差 | .08448–.08549 |
| 默认Graph相对CPU解误差 | .008939–.008963（约.895%） |
| rho1e-16 Graph相对CPU解误差 | 约9.94e-9–1.02e-8 |
| rho1e-16 Graph真相对残差 | 约.994e-7–1.057e-7，仍未达1e-8旧严格参考门槛 |

SpMV重复输出相对差约2.4e-16–3.2e-16，预条件器重复输出逐位一致。CPU准确解稳定、同固定系统PCG本身重复不一致，为“微小浮点差异在迭代中被放大”提供证据；**尚未通过确定性算子替换证明SpMV是唯一原因**，不能直接归咎于CUDA Graph，因为host也有同量级变化。

准确CPU布料最大轴向方向速度约4.183820m/s，默认Graph固定重放约4.1788–4.1790m/s。固定系统分析修正了“没有准确线性参考”的局部限制，但没有自动消除原非线性/质量问题，也没有据此修改生产PCG容差。

## 综合决策与下一步

本轮不直接增加六次迭代阈值，也不全局切换velocity_only。固定兔子证明了停止选择会改变后续轨迹，但更充分求解增加成本、未提供物理真值；落球则在更早的线性阶段已不够可重复。只修外层停止，不能消除这两个层次的混杂。

下一项优先使用已冻结的落球f30_n1系统，验证固定归约顺序的SpMV/PCG重复性，保持A/b、预条件器、rho和迭代预算不变，用本轮CPU解同时比较重复差、真残差和成本。必须先在固定系统上有收益证据，再做默认关闭的实际轨迹验证；不从新轨迹中反复追逐已变的系统。不将落球结论直接推广到旧混合体FEM大方向问题。v54候选继续默认关闭，混合体质量匹配加速仍未验收。
