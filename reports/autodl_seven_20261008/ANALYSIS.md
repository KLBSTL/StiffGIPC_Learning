# 七场景 AutoDL 120 帧结果分析

本轮完成 21/21 次从零连续 120 帧运行，七场景均取得三臂完整结果。原生退出码、帧数、配置、已观测 PCG 触顶／breakdown、有限状态及输入身份检查均通过。原版 breakdown 观测并不完整，独立接受路径 CCD 未审计，因此这不是物理质量认证。

时间结果见 [REPORT.md](REPORT.md)，全部 21 行阶段数据见 [TIMINGS.csv](TIMINGS.csv)，完整工作量、材料、轨迹差异见 [RESULTS.json](RESULTS.json)。本轮保留各臂一次；没有统计置信区间、分量消融或新增模拟。

## 收益及其边界

- **已验证：**单次 Graph-only / Stiff 为 1.049–1.269×；完整组合 / Stiff 为 1.075–1.414×。
- **已验证：**七场景比值的描述性几何平均分别为 1.187×、1.263×，Graph→完整组合为 1.064×。这些是不同场景的描述统计，不是重复运行的置信界或同质量认证。
- **已验证：**最好的总比值是悬挂 L 的 1.414×；最大的 Graph-only / Stiff 比值是固定兔子 L 的 1.269×。没有场景达到 2×。
- **支持但未证明：**Graph 主要降低线性阶段执行成本；本轮没有活动 host 臂，不能把原版与活动 Graph 的所有时间差严格归于 Graph。
- **待验证：**四项组件的独立收益。Graph→all 仅是 FullCCD refit、批量能量、能量复用及普通 BVH refit 的组合增量，不能把它按四个单独倍数拆分。

配置均为 IPC、legacy MAS、rho=1e-4、dt=.01、累计阈值 .01、最少六次有效更新、K1、完整安全 CCD。all 不包含 AL-TOI、残差停止实验、退休融合、接触池，也不包含尚未实现的分段能量归约或行邻接 SpMV。

**已验证：**混合兔子 all 比 Graph 只增量 1.025×。CCD／线搜索合计少约 0.344 秒，但装配和线性分别增加约 0.040／0.030 秒，抵消部分收益。装配还占 all 求解约 21.1%，Graph 能覆盖的比例较低。

PCG 总量在 base/all 间变化 −1.78%～＋1.00%，整体收益并不是靠大幅减少 PCG 迭代取得；Newton 和轨迹仍有差异，阶段变化同时包含工作量变化和执行变化。
按本轮工作结构，要把 all 再压到 base 的一半，仍需节省当前 all 的约 29.3%～46.2%。仅有小幅调度优化不足以宣称 2× 已近完成。
